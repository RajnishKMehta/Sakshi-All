# Contributing to Sakshi Portal

Thank you for your interest in contributing to **Sakshi Portal**! We welcome and appreciate contributions of all forms, including bug reports, feature requests, documentation improvements, and code changes.

## Code Guidelines

- **English Only**: All code, comments, documentation, commit messages, and issues must be in English.
- **Best Practices**: Keep code clean, modern, and production-ready.
- **UI Toolkit**: Follow modern Jetpack Compose guidelines for the UI, as Portal is the user-facing Compose UI gateway.
- **KDoc**: Add proper KDoc documentation for any new public APIs or important classes.
- **Testing**: Maintain high test coverage. Ensure all unit tests pass before submitting code.

## Submitting Pull Requests

1. Fork the repository and create your branch from `main`.
2. Commit your changes with a clear and descriptive commit message.
3. Verify your changes using `./gradlew test` and `./gradlew assembleDebug`.
4. Open a Pull Request referencing the issue you are addressing.
