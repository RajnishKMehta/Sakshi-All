# Reference

Welcome to the Sākṣī Reference Documentation.

This section provides precise technical specifications, API contracts, data models, error definitions, and ecosystem constraints for developers working with Sākṣī.

Unlike the [Developer Guide](../developer-guide/README.md), which focuses on integration tutorials, architecture concepts, and "how-to" explanations, this section serves as a strict technical dictionary for the implemented features.

## Contents

- [API Reference](api/README.md): Detailed specifications of the public `SakshiClient` interface.
- [Data Models](data-models.md): Field-level descriptions of all SDK request and response payload structures.
- [Error Codes](error-codes.md): Complete list of SDK `SakshiError` constants and their meanings.
- [Validation Constraints](validation-constraints.md): The specific string validation requirements enforced by the ecosystem (e.g., file IDs, media types).
- [Configuration](configuration.md): Supported connection configurations for the SDK.
