# Changing the Vault in Camera

By default, Sākṣī Camera automatically detects and connects to the official Sākṣī Vault. However, if you have installed a compatible alternative Vault app created by a different developer, you can configure Camera to use it instead.

*Note: Changing the Vault in Camera only affects the Camera app. If you also use Sākṣī Portal, you must change its Vault setting separately.*

## How to Change the Vault

1. Open the **Sākṣī Camera** app.
2. Tap the **Settings** icon.
3. Tap **More Settings**.
4. Scroll to find the **Change Vault App** setting.
5. Tap **Change Vault App** (or the row containing the package name).
6. The "Select Vault App" dialog will appear, listing all installed apps that are compatible with the Sākṣī SDK.
7. Tap the alternative Vault app you want to use.

The Camera will immediately update its configuration to use the newly selected Vault package for all future media storage.
