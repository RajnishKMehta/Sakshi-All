# Sākṣī User Guide

Welcome to the Sākṣī ecosystem user guide. This guide will help you set up and use the Sākṣī applications to preserve your important media.

Sākṣī consists of separate applications that work together:

1. **Vault**: The background app that securely stores your media.
2. **Camera**: The app for capturing new photos and videos.
3. **Portal**: The app for viewing and managing stored media.
