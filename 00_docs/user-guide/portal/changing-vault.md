# Changing the Vault in Portal

Sākṣī Portal automatically connects to the official Sākṣī Vault upon installation. If you are using a custom or third-party compatible Vault application, you must explicitly select it in the Portal settings.

*Note: Changing the Vault in Portal only updates where the Portal looks for media. It does not change where the Sākṣī Camera saves media. You must update Camera separately.*

## How to Change the Vault

1. Open the **Sākṣī Portal** app.
2. Tap the **More Options** (three vertical dots) menu in the top right corner.
3. Tap **Settings**.
4. Tap the **Select Vault App** option. (If a vault is currently selected, its package name is displayed below this option).
5. The "Select Vault App" screen will open, scanning your device for compatible apps.
6. Find the new Vault application in the list and tap it.

The Portal will immediately connect to the new Vault. When you return to the main gallery screen, it will refresh to display the media stored in the newly selected Vault.
