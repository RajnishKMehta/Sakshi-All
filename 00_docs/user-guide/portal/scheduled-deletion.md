# Scheduling Deletions and Recovery

Sākṣī Vault does not delete files immediately when you request it. Instead, it uses a delayed deletion system to protect against accidental or forced removal.

When you delete a file from the Vault using the Portal, it is **scheduled for deletion** and hidden from the main gallery. The Vault will permanently erase it after 30 days.

## How to Schedule a Deletion

1. Open the **Sākṣī Portal** and tap a photo or video to view it.
2. Tap the **Schedule deletion** icon (a trash can with a clock) in the top right corner.
3. A confirmation dialog will appear explaining that the file will be hidden now and permanently deleted from the Vault after 30 days.
4. Tap **Schedule deletion** to confirm.
5. The file is removed from the main gallery.

*Note: This action only affects the copy inside the Vault. Any copies you previously exported/saved to your device, or the original files taken by your phone's camera, are not affected.*

## Viewing and Recovering Scheduled Deletions

If you change your mind within the 30-day window, you can recover the file.

1. On the main gallery screen, tap the **More Options** (three vertical dots) menu.
2. Tap **Recover Media** (or "Scheduled Deletions").
3. The gallery will now display only the files that are currently scheduled for deletion.
4. Tap the file you want to recover to open the viewer.
5. Tap the **Recover** icon (a clock with an arrow) in the top right corner.
6. A confirmation dialog will appear. Tap **Recover**.
7. The file is restored to the normal gallery and the scheduled deletion is canceled.

To return to the normal gallery, tap the back arrow in the top left corner of the Scheduled Deletions screen.
