# Adding Media to Vault

The **Add to Vault** feature allows you to securely import photos, videos, and other files from your device into the Sākṣī Vault.

## How to Import Files

1. Open the **Sākṣī Portal** app.
2. Tap the **three-dot overflow menu** (⋮) in the top-right corner.
3. Select **Add to Vault**.
4. The Android system file picker will appear. You can browse your device and select one or multiple files to import. (Long-press a file to start selecting multiple items).
5. Tap **Select** or **Open** to confirm.

## Import Progress

Once you confirm your selection, Portal will securely copy the files into the Vault.

- A progress bar will appear at the bottom of the screen showing you how many files have been successfully imported.
- You can minimize the progress display by tapping the **minimize icon** (▼). When minimized, a small persistent indicator will remain at the bottom of your screen.
- You can continue to browse your Vault or use the Portal app while the import happens in the background. Minimizing the progress indicator **does not** cancel the import.
- To see the full progress again, simply tap the minimized indicator.

## Verification and Errors

When the import completes, the progress view will display an **Import Summary** showing the number of files successfully added and any that failed.

- You can verify the files by refreshing the gallery (pull down from the top of the screen). The newly imported items should appear in your Vault.
- If an individual file fails to import (for example, if the file is corrupted or cannot be read), the system will skip it, count it as a failure, and continue importing the rest of your selection.
