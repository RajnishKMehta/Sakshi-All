# Sākṣī Developer Guide

Welcome to the Sākṣī Developer Guide. This guide provides the necessary information for Android developers who want to understand the system architecture or build applications that integrate securely with the Sākṣī ecosystem.

Here you will find documentation covering the fundamental concepts of the decentralized architecture, how to properly configure your Android project to depend on the SDK, and comprehensive references for all available interactions.

## Contents

- [Architecture & Concepts](concepts/architecture.md): Understand the distinct responsibilities of the Vault, SDK, Camera, and Portal components, and how they communicate.
- [SDK Integration](sdk/integration.md): Step-by-step instructions on setting up Gradle, Manifest permissions, and initializing the SDK.
- [API Reference](sdk/api/README.md): Detailed documentation for every public method available in the `SakshiClient`.
