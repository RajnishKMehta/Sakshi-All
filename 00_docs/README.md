# Sākṣī Documentation

This repository contains the documentation for the Sākṣī Android ecosystem.

Sākṣī helps preserve a separate local copy of important photos and videos using an independent background storage application called Vault. The ecosystem includes Camera, Portal, Vault, and the developer SDK.

## Documentation

- **[Overview](overview/README.md):** introduction to Sākṣī and its components.
- **[User Guide](user-guide/index.md):** installation, everyday usage, camera and portal workflows, and troubleshooting.
- **[Developer Guide](developer-guide/README.md):** SDK integration, architecture, and development documentation.
- **[Reference](reference/README.md):** SDK APIs, data models, error codes, and configuration parameters.
