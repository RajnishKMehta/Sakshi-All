== 1. Prerequisites

* **Java JDK**: 21 (OpenJDK 21 LTS)
* **Android SDK**: Compile SDK 37, Min SDK 29
* **Gradle**: 9.6.1

== 2. Building the Project

[source,bash]
----
# Clean and assemble release library
./gradlew clean :sakshi-sdk:assembleRelease

# Run lint and checks
./gradlew :sakshi-sdk:check
----

== 3. Coding Guidelines

* **Kotlin Only**: All source files must be written in idiomatic Kotlin.
* **Strict Explicit API Mode**: Requires `public`, `internal`, or `private` on all classes and functions.
* **KDoc Requirement**: Comprehensive KDoc documentation must accompany all public symbols.
