# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability within **Sakshi SDK**, please report it responsibly by emailing **RajnishKMehta@proton.me** instead of opening a public GitHub issue.

Please include:
* A detailed description of the vulnerability.
* Steps to reproduce the issue.
* Any relevant logs or code snippets.

We will acknowledge receipt of your report within 48 hours and provide status updates as we work on a fix.
