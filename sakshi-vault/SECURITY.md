# Security Policy

## Supported Versions

We actively support and patch the latest version of Sakshi Vault:

| Version | Supported |
| --- | --- |
| 1.0.x | :white_check_mark: |
| < 1.0 | :x: |

## Reporting a Vulnerability

We take the security of Sakshi Vault seriously. If you find any security vulnerabilities or concerns, please report them privately.

Do **NOT** open a public issue for security-related matters.

Instead, please send an email to the author:
**Rajnish Kumar** (<RajnishKMehta@proton.me>)

Please include a detailed description of the vulnerability, steps to reproduce, and any suggested fixes if available. We will acknowledge your report within 48 hours and work with you to patch the issue promptly.
